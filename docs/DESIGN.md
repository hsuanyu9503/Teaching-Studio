# DESIGN｜視覺與互動規格

> 版次：D0.1　｜　最近更新：2026-11-15　｜　核准狀態：**草案**（Stage 0 僅建立暫定 Tokens；正式視覺方向待 ChatGPT 設計與使用者核准）
>
> 依據：SPEC 原文 §5.4 視覺方向、§11 工具抽屜。

## 1. 設計目標

- 視覺關鍵字：簡潔、低干擾、專業；**教材是主角**
- 避免的風格：高飽和裝飾色、搶眼動畫、遮擋教材的常駐元件
- 情境：課前準備（桌機／iPad）、課堂投影（16:9，學生於教室後方閱讀大型展示）

## 2. 設計 Tokens

| 項目 | 值 | 用途 |
|---|---|---|
| `--ts-bg` | `#15181c` | 工作台外框（深色中性） |
| `--ts-surface`／`--ts-surface-2` | `#1f2329`／`#2a2f37` | 面板、按鈕 |
| `--ts-border` | `#3a404a` | 分隔線 |
| `--ts-text`／`--ts-text-muted` | `#eef1f4`／`#a9b1bb` | 主要／次要文字 |
| `--ts-accent` | `#5aa9e6` | 焦點框、連結 |
| `--ts-ok`／`--ts-danger` | `#5cc98a`／`#f07167` | 狀態 |
| `--ts-radius` | `10px` | 元件圓角 |
| `--ts-touch` | `44px` | 觸控目標最小尺寸 |

> 暫定值，定義於 `src/app/global.css`；不代表已定稿。教材區域不套用任何濾鏡或底色，保留原色。

## 3. 排版與響應式

- 手機：360px 至 599px，優先單欄。
- 平板：600px 至 1023px，依功能適度雙欄。
- 桌面：1024px 以上。
- 需要特殊投影比例時：`[請明確記錄 16:9 等條件]`。
- 圖片不得未經同意任意裁切或拉伸。

| 頁面 ID | 用途 | 區塊與排序 | 操作方式 | 重要狀態 |

| P-001 | 工作台（Stage 1 起） | 頂部列／左教材清單／中央播放區／右工具抽屜／底部播放控制（SPEC §5.1） | 點選、拖曳、鍵盤、觸控 | 無教材引導、載入中、載入失敗 |

## 6. 素材管理

正式素材放在 `src/assets/`（見 `docs/ASSETS.md`），交由 Claude 整合。每批素材附 `templates/VISUAL_HANDOFF.md`，指明：檔名、用途、尺寸／比例、裁切規則、透明背景與響應式行為。未提供正式素材的區塊可先使用佔位圖，不得擅自定稿。
